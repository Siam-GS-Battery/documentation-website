# General Information

This document serves as a formal reference for the management of the Production Planning Dashboard project deployed on the AWS QuickSight cloud platform. It is designed to support two distinct user groups: general users and administrative users. For general users, the document provides instructions on how to access and interact with the dashboard's visualizations. For administrative users, it offers detailed guidance on maintaining, configuring, and designing visuals to meet the information needs of general users.

## 1.1 Introduction

This document serves as a formal reference for the management of the Production Planning Dashboard project deployed on the AWS QuickSight cloud platform. It is designed to support two distinct user groups: general users and administrative users. For general users, the document provides instructions on how to access and interact with the dashboard's visualizations. For administrative users, it offers detailed guidance on maintaining, configuring, and designing visuals to meet the information needs of general users.

## 1.2 Precautions and Usage Instructions

### 1.2.1 Handling Visual Errors

If you faced with error visual situations as figure 1, please follow these steps:

1. **Locate and select the button** at the top left corner of the screen, as the figure 2.
2. This action will help you refresh or navigate away from the error screen as needed.

### 1.2.2 Tips and Tricks

Here is tips and tricks for faster loading AWS QuickSight Dashboard, you able to open more than 1 tab to load dashboard at once, please follow these steps:

1. **Right-click the QuickSight logo** located at the top-left corner of the screen, as shown in Figure 3.
2. Select **"Open link in new tab"** or **"Open link in new window"** from the context menu.
3. In the newly opened tab or window, select the desired dashboard you wish to view, as shown in Figure 4.
